# Triage

Triage is a short pass over the inbox, one card at a time.

Open it from **Inbox (n)** on Today. On the first open of a day, if the inbox has anything in it, triage opens by itself. **Back to Today** dismisses it. It will not force itself open again until tomorrow.

The line above the card says how many are left, such as **4 left**.

## The buttons

| Button | What happens |
|---|---|
| Today | Becomes Now if Now is empty. Otherwise it becomes Next. If Next already has two, you choose which one moves to This week, or you send the new one to This week. |
| This week | Waits on the This week list. |
| Someday | Waits on Someday. If the card already has a calendar block, ZigZag asks **Remove the block** or **Keep the block**. |
| Delete | Removes the card. **Undo** sits there for a few seconds. |
| Skip | Puts this card at the back of the inbox. |
| Send the rest to Someday | Shows up when the inbox is long (about 15). The card you are looking at stays. The others go to Someday. |

**Undo** puts the last This week, Someday, or Delete back.

When the inbox is empty, the screen says **Inbox clear. Today is set.**
