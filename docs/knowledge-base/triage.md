# Where it goes

You place an item while you add it. Today does not send you to a second screen.

## When you type it

| Button | What happens |
|---|---|
| Now | Becomes the one Now card. The previous Now moves into Next. If Next already has two, the later one moves to This week. |
| Today | Becomes Now if Now is empty. Otherwise it becomes Next. If Next already has two, the new item goes to This week. |
| This week | Waits on the This week list. |
| Enter | Uses whichever of those three is open. The line under the field names it. |

## When something arrives

A shared email or a Deep Roots card shows on Today under **Add something**. The line says how many are waiting, such as **3 waiting**. One card at a time.

**Now**, **Today**, and **This week** place it. **Someday** holds it off this week. **Delete** removes it, and **Undo** sits there for a few seconds. When more than 15 are waiting, **Send the rest to Someday** keeps the card you are looking at and moves the others.
