# Calendars

Zoho and Google are there so you can see what is already on the clock. ZigZag does not turn every meeting into a task.

## What you see

Events for the next seven days appear on the top line and in the list you open from it. Each one is labeled **Zoho** or **Google**.

**Add to today** is manual. ZigZag will not file a meeting for you. If Today already has one Now and two Next, the button says **Add to this week**.

If a calendar does not answer, your tasks stay. Settings can say **Zoho didn't answer. Your tasks are still here.** or the same for Google. Today does not grow an error banner.

## What ZigZag writes

ZigZag only changes events it created.

- **Put on calendar** on a task that has a due date.
- **Block recovery**, once a home calendar is connected.

The home calendar is the one you save in Settings. Saving Zoho as home clears Google as home, and the other way around. You can still read both.

## When the times disagree

If you changed the task and the calendar event also moved, Today says **Calendar time differs.**

- **Keep task time** keeps your task and updates the event.
- **Use calendar time** moves the task to the event's time.

Neither one is pre-selected. Meetings ZigZag did not create are left alone.

If someone deletes a ZigZag event on the calendar, the task stays. The link drops.
