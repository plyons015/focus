# Time and recovery

ZigZag shows the time so you can see where you are. It does not run a countdown, and it does not tap you on the shoulder while you are still on Now.

## The top line

The line under the name is the clock, in Pacific time. If something is dated in the next seven days, the same line names it, for example:

**3:40 pm · Next: Today 4:00 pm · Staff meeting**

Tap that line to open the list. The list can include:

- A task with a due date
- A recovery block
- A Zoho or Google event

Each row says what it is: Task, Recovery, Zoho, or Google. A meeting is not a task. **Add to inbox** turns one into an inbox card when you want that.

There is no month grid.

## Due dates

On a Now card, **Details** has **Due date**. **Clear date** removes it. A due date shows on the top line. It is not labeled late.

**Put on calendar** appears when a due date is set and a home calendar is connected. It asks ZigZag to place a block on that calendar at the next sync.

## Recovery

After **Done** or **Park**, one line asks **Block recovery?** You can ignore it. Tap elsewhere or **Close**, and nothing is created.

If you want the block, pick **15 min**, **30 min**, or **60 min**. It starts at the next half hour. An exact half hour moves forward. The block shows on the top line like any other dated item. The title is Recovery.

If a home calendar is connected, that block is also written there as a busy event after the next sync. The block exists on Today even when no calendar is connected.
