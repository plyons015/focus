# Settings

Open **Settings** from the bottom bar. Connections live here. Today already works if every row says **Not connected**.

Step by step: [Connect Deep Roots](connect-deep-roots.md), [Connect Zoho](connect-zoho.md), [Connect Google Calendar](connect-google-calendar.md), and [Sign in with Google](sign-in-with-google.md).

## What you can set

| Row | What to enter |
|---|---|
| Connect Deep Roots | Your Deep Roots user id and the site address. **Save**. |
| Import a Deep Roots snapshot | A JSON snapshot, if the live sync is not running yet. **Save** puts those cards on Today, waiting. |
| Zoho | The calendar id you want new blocks written to. **Save** makes it the home calendar. |
| Google | Same as Zoho. Saving it makes Google home and clears Zoho as home. |

**Connected** means you saved that row. Events and check-offs show up after the next sync, which is what **Events show up after the next sync** means.

## What Settings will not do

There is no setup progress, no badge, and no first-run wizard. Leaving a row empty does not mark Today.

**Sign out** appears only after you have signed in to Firebase. Signing out keeps the choice to use this device only available again.
